Hand-off rules

Baked into every component above

Accessibility
  • Text ≥ 4.5:1; controls and icons ≥ 3:1.
  • Every interactive element carries the 2px ink + ember-200 focus ring.
  • Colour is never the only signal — chips keep labels, badges keep icons, the switch knob keeps its check.
  • role="switch", aria-sort, aria-current="step", tablist, listbox and dialog roles are marked in the markup.
Layout resilience
  • No fixed widths on text containers, so +40% translated strings wrap instead of clipping.
  • Flex and grid with gap throughout; nothing spaced by margins on siblings.
  • Logical properties for padding and margin, so the whole set mirrors for RTL. Only arrows and chevrons flip.
  • Controls hold WordPress's 40px height (36px compact, 44px touch).
Implementation
  • Every value reads from a --sd-* custom property; no hard-coded hex inside a component.
  • Everything scoped under .sd-app; WordPress itself is never restyled.
  • Modal 100010, drawer 100000, toast 100020 — above the toolbar's 99999.
  • Motion respects prefers-reduced-motion; the running dot stops pulsing.
