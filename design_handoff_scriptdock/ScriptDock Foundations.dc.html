Usage rules
  • Clear space around the lockup equals the height of the dot on all four sides.
  • Minimum wordmark width 96px; below that use the mark alone.
  • The gradient never appears on the sidebar icon, in the admin bar, or on anything WordPress recolours.
  • On dark chrome the wordmark is white and the dot keeps its gradient; never reverse the dot to white.
Two rules learned the hard way
1 · Never dim a card with opacity A wrapper opacity composites every child, including the sentence explaining why the card is unavailable — which is exactly the text the user needs most. Express "blocked" with tokens instead: gray-700 heading, gray-600 body, gray-600 icon strokes, and the lock chip at full ink on a gray-50 ground.
2 · The code gutter is body text, not chrome Line numbers look decorative but every error message in the product points at one — "Line 3 · unexpected '}'", "Jump to line 12". Light gutters use gray-700 on gray-50, never gray-500. Dark gutters use #8A847B on #1B1916.
