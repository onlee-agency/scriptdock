Safety & security

Safe mode link

Open this link and every snippet pauses in your browser only — visitors still see the site as normal. Save it somewhere outside WordPress, because you will need it when the admin will not load.

https://lumencoffee.com/wp-admin/index.php?scriptdock_safe_mode=q7m2x9w4k8r1t5v3n6p0
Generating a new link breaks the old one immediately. You can also set SCRIPTDOCK_SAFE_MODE in wp-config.php to force safe mode for everyone.
Tamper protection On Signing with your WordPress security keys.

Every snippet is signed when you save it. If the code changes in the database without going through ScriptDock, it stops running until you approve it.
