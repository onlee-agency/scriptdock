# ScriptDock 1.0.0

Paste this into the GitHub release body when tagging `v1.0.0`. WordPress shows
it in the plugin's "View details" panel, so it is written for the person about
to install it rather than for a diff.

---

The first release. ScriptDock adds PHP, HTML, CSS and JavaScript to a WordPress
site — everywhere, on one page, or only where you say — and is built so that a
mistake in that code cannot take the site down.

Everything is included. There is no Pro version, no locked features, no ads and
no tracking.

## Why it is not in the WordPress.org directory

Since 1 September 2026 the plugin directory does not accept new plugins that
allow arbitrary code insertion or execution. Plugins like WPCode and Code
Snippets were approved years before that rule. ScriptDock is therefore
installed from GitHub and updates itself from GitHub releases. It still follows
WordPress's coding and security standards.

## What it does

**Add code anywhere.** Five types — PHP, HTML, CSS, JavaScript and Universal
(HTML with embedded PHP) — in 33 places: the head, after `<body>`, the footer,
before or after content, before or after paragraph N, between posts, excerpts,
admin screens, the login page, the block editor, twelve WooCommerce hooks, any
action hook you name, or only where you place a shortcode or the ScriptDock
block. PHP can run everywhere, on the front end only, in the admin only, or on
demand for a one-off job.

**Say where it runs, in plain language.** A five-step wizard covers placement,
pages and content, audience and schedule, and writes what you chose as a
sentence — "Runs in the site header on Pricing and Contact, for logged-out
visitors, on mobile" — with a live count of matching pages and a URL tester.
Thirty-three rules are available, including URL patterns, user roles, devices,
times of day, languages, your own PHP function and WooCommerce cart contents.
The raw AND/OR rule builder is still there behind an "Advanced rules" switch.

**Per-page code.** Every post and page gets a ScriptDock panel: head, body,
footer, before and after content, CSS and JavaScript for that page alone, plus
switches to turn off site-wide snippets on it. In the block editor it is a
sidebar panel with a full-screen code window; the classic editor keeps a meta
box. Either way it saves when you update the page.

## Safety

This is the part that matters, and it is why the plugin exists.

- **Crash protection.** PHP is syntax-checked as you type and again on save,
  and code that runs everywhere is test-run before it is switched on. If a
  snippet still causes a fatal error — even later, inside a hook it registered
  — ScriptDock identifies exactly which one, switches it off, and emails you
  with the error, the line and the page it happened on.
- **Safe mode.** A secret link that pauses every snippet in your browser so you
  can get back in and fix things, while visitors keep seeing the site as
  normal. There is also an admin bar switch and a `wp-config.php` constant.
- **Tamper protection.** Every snippet is signed. Code changed directly in the
  database — a common way malware hides in snippet plugins — does not run until
  an administrator has looked at it and approved it.
- **Permissions.** Managing snippets needs `manage_options` and
  `unfiltered_html`; PHP additionally needs `edit_plugins`, so
  `DISALLOW_FILE_EDIT` locks PHP snippets too. On multisite, only super admins.
- **History.** Every save is a version you can compare side by side and
  restore.

## Speed

Active snippets are compiled into one signed, cached option, so a page load
makes no extra database queries. CSS and JavaScript can be served as cached
files, CSS can be minified, and scripts can load normally, deferred, async,
when the browser is idle, or on the visitor's first interaction. Any script can
be held back until the visitor consents to a category, through the WP Consent
API that Complianz, CookieYes and Cookiebot support.

## Also in the box

A 47-snippet library (Google Analytics 4, Tag Manager, Meta Pixel, TikTok,
LinkedIn, Clarity, Hotjar, Plausible, Fathom, Matomo, purchase events and
more), smart tags including WooCommerce order data for conversion tracking, a
Header & Footer screen, an editor for ads.txt, app-ads.txt, llms.txt,
security.txt and robots.txt, an admin bar inspector showing what ran on the
page you are looking at, JSON import and export, importers for WPCode, Insert
Headers and Footers, Code Snippets, Header Footer Code Manager and Simple
Custom CSS and JS, WP-CLI commands, and a Site Health check.

## Installing

1. Download `scriptdock.zip` below.
2. In WordPress, go to Plugins → Add New → Upload Plugin and choose the file.
3. Activate it. Setup opens the first time you visit ScriptDock: it takes a
   minute, and it saves your safe mode link somewhere outside WordPress.

For updates to arrive in Dashboard → Updates, set `SCRIPTDOCK_UPDATE_REPO` to
this repository in `wp-config.php`.

**Requires** WordPress 6.3 or newer and PHP 7.4 or newer.
